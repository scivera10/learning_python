# Learning Python

Este repositorio contiene proyectos, ejercicios y pequeños experimentos que he creado mientras aprendo Python.

El objetivo es utilizarlo como registro de mi progreso y reunir en un mismo lugar los proyectos que voy desarrollando a medida que aprendo nuevos conceptos de programación.

## Proyectos

### Explorador de Pi

Proyecto para generar decimales de π, transformarlos en letras y buscar patrones dentro de los datos generados.

Incluye diferentes partes:

- Generación de decimales de π.
- Conversión de los decimales a letras.
- Búsqueda de patrones numéricos y de texto.
- Análisis de los datos generados.

Carpeta del proyecto:

`explorador_de_pi/`

---

### Bingo

Proyecto de Bingo desarrollado en Python con el objetivo de practicar conceptos fundamentales del lenguaje.

La primera versión del programa permite:

- Crear un cartón con números aleatorios.
- Crear un bombo con números aleatorios sin repetir.
- Extraer y mostrar las bolas una a una.
- Comprobar qué números del cartón han salido.
- Guardar los números acertados.
- Detectar cuándo se completa el cartón.
- Finalizar automáticamente el juego cuando se consigue BINGO.

Carpeta del proyecto:

`bingo/`

Actualmente incluye:

`bingo/bingo_v1.py`
